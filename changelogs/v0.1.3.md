# v0.1.3

## Summary

Added a Cursor rule requiring tests and a pytest run when changing API, WebSocket, or CLI/terminal-related code.

## Changes

- [`.cursor/rules/api-cli-tests.mdc`](.cursor/rules/api-cli-tests.mdc) — `alwaysApply` guidance: add/update `tests/`, run `python3 -m pytest tests/ -v`, and `npm run build` in `cli/` when the TypeScript client changes.

## Rationale

Keeps HTTP/WebSocket contracts and the thin CLI from regressing by making test authorship and execution part of the agent workflow, not an afterthought.
