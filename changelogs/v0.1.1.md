# v0.1.1

## Summary

Documented where LLM inference lives and added **Hugging Face Inference API** (cloud) as an explicit backend with token configuration.

## Changes

- [`app/services/analysis/llm_refinement.py`](app/services/analysis/llm_refinement.py): `LLM_BACKEND=hf_inference` calls the hosted API via `httpx`; `transformers` path remains local `_hf_refine`.
- [`app/core/config.py`](app/core/config.py): `HF_TOKEN` (aliases `HUGGINGFACE_HUB_TOKEN`, `HUGGINGFACE_API_KEY`), optional `HF_INFERENCE_BASE_URL`.
- [`.env.example`](.env.example): documented `LLM_BACKEND` values and HF token.

## Rationale

Cloud inference avoids shipping large weights on the API host and matches “hybrid / cloud-enhanced” operation; the token must not be hardcoded and should follow HF’s standard env names where possible.
