# v0.1.2

## Summary

Added persistent Cursor instructions and a shell helper so agents consistently update `changelogs/` and `version.properties` after substantive work.

## Changes

- [`.cursor/rules/changelog-and-version.mdc`](.cursor/rules/changelog-and-version.mdc) — `alwaysApply` rule describing the mandatory changelog + version bump workflow.
- [`scripts/agent_changelog_workflow.sh`](scripts/agent_changelog_workflow.sh) — prints the workflow, lists current version and changelog files; optional `--verify` checks that `changelogs/v$(version).md` exists.

## Rationale

Centralizing this in `.cursor/rules/` ensures Cursor agents load the expectation every session; the script gives a quick human/agent reference without opening the rule file.
