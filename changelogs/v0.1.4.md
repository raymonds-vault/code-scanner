# v0.1.4

## Summary

Added IDE debugging for the FastAPI backend via **debugpy**, VS Code/Cursor **launch configurations**, and an optional attach helper script.

## Changes

- [`requirements-dev.txt`](requirements-dev.txt) — includes `debugpy` and pulls in `requirements.txt`.
- [`.vscode/launch.json`](.vscode/launch.json) — **Shield: FastAPI (uvicorn, debug)** (no reload, reliable breakpoints), **reload + subprocess** variant, **Attach debugpy (5678)**, **Pytest** configurations.
- [`scripts/run_with_debugpy.py`](scripts/run_with_debugpy.py) — run uvicorn after `debugpy.listen` / `wait_for_client` for attach-from-terminal workflows.

## Rationale

`debugpy` + `launch.json` is the standard path for Cursor/VS Code Python debugging; reload mode uses `subProcess: true` so the reloader child can be debugged when needed.
